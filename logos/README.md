# Tool logos

91 marks for every tool named in **PaidVsOpenSource.html**, for use as video overlays.

| Folder | What's in it |
| --- | --- |
| `paid/` | 50 name-brand marks, original format (SVG where available) |
| `open-source/` | 41 open source project marks, original format |
| `png-512/` | Every one of the 91, re-rendered to a 512×512 transparent PNG. Use these if your editor won't import SVG. |

Mirrored subfolder structure, one file per tool, filename = kebab-case tool name.

## Provenance

Sources, in order of preference: Simple Icons (official brand SVG, brand colour) → the project's own GitHub org avatar → the vendor's own site assets → a project repo asset.

## Caveats

- ⚠️ marks a source raster smaller than 256px. The 512px PNG is upscaled and will soften if you fill more than about a quarter of a 1080p frame. Fine as a small overlay.
- **mixpost** uses Inovector's org mark (a red square) because Mixpost ships no standalone logo. It reads as a generic shape on screen, so consider a text label next to it.
- **open-higgsfield-ai**, **voicestudio** and **openseo** are small community repos with no project logo. They use the GitHub mark as a stand-in rather than a maintainer's profile photo.
- **firebase** doubles as the mark for Firebase Cloud Messaging; **supabase** covers both hosted and self-hosted; **sentry** covers Sentry self-hosted; **bitwarden** covers the Bitwarden server.
- These are third-party trademarks, collected from public brand assets. Editorial/commentary use in a video is normally fine; check the vendor's brand guidelines before implying endorsement.

# CLAUDE.md

## About this directory

This is a dumping ground for many independent projects: guides, skills, and
documents (HTML, PDF, Markdown, .skill files, subfolders like
`ai-engine-optimization/`, `business-memory/`, `markdown/`, etc.). Files here
are almost never related to each other — a guide about AI careers has nothing
to do with a skill for humanizing text, which has nothing to do with a
markdown style guide.

## How to behave here

- **Do not proactively read, search, or scan files in this directory** unless
  the user explicitly names a file/folder, or the current task clearly
  requires it. Don't glob/grep across the repo "just to see what's here."
- **Treat each file/folder as its own isolated project.** Don't assume
  conventions, terminology, or content from one file apply to another.
- **Exception — modeling a new document off an existing one:** if the user
  asks to create something "like" or "based on" an existing file, it's fine
  (expected) to read that referenced file for structure/style/tone. Only read
  the one(s) they pointed at, not surrounding files.
- If you're unsure whether a file is relevant, ask the user rather than
  opening it to check.
